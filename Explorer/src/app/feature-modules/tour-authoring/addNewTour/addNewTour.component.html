🛠 How to Create a Tour?

Creating a tour is simple! Just follow these steps:

1

Name & Description

Give your tour a catchy name and an engaging description. What makes it special?

2

Difficulty & Tags

Set the difficulty level and add tags (e.g., historical, adventure, nature) to help users find it.

3

Checkpoints

Every tour needs at least two checkpoints before you can finalize it. Add as many as you want!

4

Checkpoint Details

  • Name & Description – What makes this location interesting?
  • Secret Info 🔒 – Add a hidden fact or story that unlocks only when a tourist reaches the spot.
  • Image (Optional) – Upload a picture to make it more immersive.
  • Encounters (Optional) ⚔️ – Add an interactive element with an action and description.
  • Map Location 📍 – Place the checkpoint precisely on the map.

Once you're happy with your tour, finalize it and share your adventure with the world! 🌍✨
